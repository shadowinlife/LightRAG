# Wiki 索引

本地记忆区的 wiki 分区：记录项目状态、架构地图与开发上下文。
规范细节一律指向仓库内文档（根 `AGENTS.md`、`docs/design/`、`GLOSSARY.md`），这里只存索引与带日期的快照。

| 文件 | 内容 | 什么时候读 |
|---|---|---|
| [status.md](status.md) | 仓库 / 分支 / 本地改动快照、上游近期里程碑 | 需要知道「现在仓库处于什么状态」时 |
| [architecture.md](architecture.md) | 模块地图 + 契约索引（触哪个模块先读哪份契约） | 动手改代码前定位模块与必读契约 |
| [context.md](context.md) | 本机开发环境、工作流约定、本地工具链 | 新会话需要环境与命令背景时 |

维护规则见 [../AGENTS.md](../AGENTS.md)。
